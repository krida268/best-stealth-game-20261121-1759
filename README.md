Lentera Malam is a complete top-down stealth game that runs offline in a desktop browser: sneak Rara through three moonlit gardens, past patrolling guards and their vision cones, steal back the lantern, and reach the green gate unseen.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Move with WASD or the arrow keys, hold Shift to sneak quietly, press P to pause and M to mute. Bushes hide you, walking makes noise the guards can hear, and a guard that spots you gives chase — get caught three times in a level and the night is over.
